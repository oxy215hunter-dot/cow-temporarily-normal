# 奶牛暂时正常

一头牛出门走走。黑白各有各的打算。

一个向左展开的荒诞小故事。按住左方向键、A、空格或画面下方的按钮前进，松开后停留，看看颜色会发生什么。也可以点击进度条切换场景。

插画、动画、音乐和音效随网页提供。首次点击或按键后开启声音，可在右上角关闭。

此仓库用于 GitHub Pages 静态部署，发布源为 main 分支根目录。
